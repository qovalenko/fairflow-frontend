# Продукты и цены

Раздел «Продукты» — это каталог того, что вы продаёте в рамках проекта: товаров, услуг, тарифов. Продукт можно связать с типом продажи, чтобы при оформлении сделки сразу подтягивались нужные поля и этапы, а в разделе цен — удобно держать единый прайс-лист.

Продукты живут *внутри проекта*. Просматривать каталог могут все участники (Viewer и выше), а создавать и редактировать продукты, а также управлять ценами — менеджеры и выше (Manager+).

## Каталог продуктов

Главный экран раздела — карточки всех продуктов проекта с поиском и фильтрами.

**Как открыть:** в боковом меню проекта выберите пункт «Продукты» (адрес `/products`).

### Что есть на экране

- **Заголовок** и кнопка **«Продукт»** для создания (доступна с правами Manager+).
- **Поиск** — поле «Поиск продуктов...» по названию.
- **Фильтр по категории**.
- **Переключатель «Активные / Архив»** — показывать действующие продукты или убранные в архив.
- **Карточки продуктов** — для каждого видны название, категория, цена, привязанный тип продажи и метка «Архив», если продукт архивный.

Клик по карточке открывает страницу продукта.

### Создание продукта (drawer)

Кнопка «Продукт» открывает боковую панель «Создать продукт» с полями:

- **Название** (обязательно);
- **Описание**;
- **Категория** — выбор из существующих или ввод новой;
- **Цена** и **единица** (как продаётся цена — см. ниже);
- **Тип продажи**.

> 💡 Если каталог пуст, на экране появится приглашение создать первый продукт.

## Карточка продукта

Страница продукта показывает его описание, цену, связь с типом продажи и статистику использования.

**Как открыть:** кликните по карточке в каталоге (адрес вида `/products/:id`).

### Что есть на карточке

- **Шапка** — название, категория и цена.
- **Описание** — текстовое описание продукта.
- **Тип продажи** — если назначен, по продукту можно оформлять продажи. Если не назначен, на карточке появится напоминание: продажи по такому продукту недоступны, пока тип не выбран.
- **Предзаполняемые поля продажи** — значения, которые автоматически подставятся в продажу при выборе этого продукта.
- **Использование** — сколько сделок связано с продуктом и сколько продаж по нему создано.

### Действия (Manager+)

- **Редактировать** — переход к форме редактирования.
- **Архивировать** — убрать продукт из активного каталога, не удаляя данные.
- **Удалить** — удаление продукта навсегда.

## Редактирование продукта

Расширенная форма с настройками цены и предзаполнения.

**Как открыть:** на карточке продукта нажмите «Редактировать» (адрес вида `/products/:id/edit`). Доступно с правами Manager+.

### Что можно настроить

- **Основное:** Название (обязательно), Описание, Категория.
- **Тип продажи** — связь с типом, который определяет поля и этапы продажи.
- **Ценообразование:** базовая цена и **единица** — как считается цена:
  - *Разовый* — единоразовый платёж;
  - *Ежемесячно* — цена за месяц;
  - *Ежегодно* — цена за год.
- **Предзаполняемые поля продажи** — значения по умолчанию для полей, которые приходят из выбранного типа продажи.

После изменений нажмите «Сохранить».

## Прайс-лист (цены)

Отдельный экран для управления ценами всех продуктов сразу — удобно, когда нужно пересмотреть цены без захода в каждый продукт.

**Как открыть:** в разделе «Продукты» перейдите к ценам (адрес `/products/pricing`). Доступно с правами Manager+.

### Что есть на экране

- **Таблица с ценами** — колонки Продукт, Категория, Цена, Единица.
- **Редактирование прямо в таблице** — нажмите на ячейку «Продукт» или «Цена», чтобы изменить значение на месте.
- **Кнопка «Сохранить изменения»** — применяет все правки разом; рядом показано число изменённых строк.

> 💡 Если продуктов ещё нет, прайс-лист предложит сначала создать продукты в каталоге.
