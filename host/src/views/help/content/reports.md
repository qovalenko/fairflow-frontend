# Отчёты

Раздел «Отчёты» показывает, как идут дела в проекте: сколько сделок открыто и закрыто, как клиенты проходят по воронке, кто из клиентов приносит больше всего, насколько активна команда и какие источники дают результат. Готовые отчёты не требуют настройки, а конструктор позволяет собрать собственный.

## Зачем нужен раздел

Отчёты превращают накопленные в CRM данные в наглядную картину. Здесь не нужно ничего считать вручную: выберите период — и система покажет метрики, диаграммы и детальные таблицы. Это помогает оценивать результат, находить узкие места в продажах и сравнивать работу сотрудников.

В разделе два экрана: **сводка готовых отчётов** и **конструктор отчётов** для собственных выборок.

## Как открыть

В боковом меню проекта выберите пункт **Отчёты**. Откроется сводка отчётов по адресу `/p/<проект>/reports`. Конструктор доступен по адресу `/p/<проект>/reports/builder` — перейти к нему можно из сводки.

## Сводка отчётов

Сводка — это набор готовых отчётов проекта, сгруппированных по вкладкам. Над отчётами расположена панель управления:

- **Период** — за какой промежуток считать данные (например, месяц).
- Дополнительные фильтры — по менеджеру и по воронке (там, где это применимо).
- Переход к конструктору отчётов.

Доступные вкладки:

- **По продажам**.
- **По воронке**.
- **По клиентам**.
- **По активности**.
- **По источникам**.

### По продажам

Общая картина продаж за период:

- Карточки ключевых показателей: новых сделок, закрыто успешно, закрыто с отказом, конверсия.
- Диаграммы динамики количества и суммы сделок по периодам.
- Средний чек.
- Переключатель **Диаграмма / Таблица** — таблица даёт детализацию по периодам: новые сделки, выигранные, проигранные, сумма выигранных, средний чек, конверсия.

### По воронке

Как клиенты движутся по этапам продаж:

- Воронка со стадиями и конверсией между ними.
- Среднее время, которое сделки проводят на каждой стадии.
- Таблица по стадиям: количество, конверсия, среднее время, число возвратов.
- Список «зависших» сделок, которые долго не двигались.

### По клиентам

Кто ваши клиенты и какие из них самые ценные:

- Карточки: новых контактов, новых компаний, контакты без сделок.
- Таблица топа клиентов по сумме выигранных сделок.
- Среднее количество сделок на клиента.

### По активности

Нагрузка и результативность команды по делам (задачам, звонкам, встречам):

- Диаграммы активностей по типам и по сотрудникам.
- Таблица по каждому сотруднику: задачи, звонки, встречи, просрочено, время до первого касания.
- Среднее количество активностей на сделку.

### По источникам

Откуда приходят клиенты и что приносит результат:

- Диаграммы количества сделок и суммы выигранных по источникам.
- Таблица по источникам: количество сделок, выигранные, конверсия, сумма, средний чек.

> 💡 Набор вкладок зависит от подключённых модулей проекта. Если модуль «Активности» выключен, вкладка «По активности» не показывается; без модуля продаж скрываются метрики продаж. А если выключены все модули-источники, отчётов не будет вовсе — включите нужные модули в настройках проекта.

> 💡 Если за выбранный период нет данных, вы увидите подсказку. Расширьте период или добавьте записи в CRM.

## Конструктор отчётов

Конструктор позволяет собрать собственный отчёт под конкретный вопрос, если готовых вкладок недостаточно. Откройте его из сводки.

Экран разделён на две части: слева — настройки, справа — предпросмотр, который обновляется по мере изменения настроек.

Настройки отчёта:

- **Сущность** — на основе чего строить отчёт: сделки, контакты, продажи или активности (доступны только сущности из включённых модулей).
- **Метрика** — что считать: количество, сумма, среднее, минимум или максимум.
- **Поле для метрики** — например, сумма сделки.
- **Группировка** — как разбить данные: по месяцам, по менеджерам, по стадиям, по источникам, по типам.
- **Фильтры** — период и дополнительные условия по выбранным полям.
- **Визуализация** — столбцы, линия, круговая диаграмма или таблица.

В области предпросмотра видны диаграмма и таблица с данными.

### Сохранение отчёта

Нажмите **Сохранить отчёт**, задайте название и выберите доступ:

- **Личный** — отчёт видите только вы.
- **Для всего проекта** — отчёт доступен участникам проекта.

## Кто имеет доступ

- **Сводка отчётов** доступна для просмотра участникам проекта, начиная с роли **Наблюдатель**.
- Вкладка **По активности** и **конструктор отчётов** доступны пользователям с расширенными правами (как правило, роль **Менеджер** и выше).
