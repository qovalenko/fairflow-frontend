# Документы и шаблоны

Модуль «Документы» хранит все файлы проекта в одном месте и помогает автоматически создавать договоры, акты и другие бумаги по заранее подготовленным шаблонам. Вместо того чтобы каждый раз вписывать реквизиты вручную, вы один раз настраиваете шаблон, а система подставляет данные из контактов, компаний, сделок и продаж.

## Зачем нужен модуль

- Единое хранилище документов проекта — и загруженных вручную, и сгенерированных системой.
- Автоматическая генерация типовых документов по шаблону — быстро и без ошибок в реквизитах.
- Контроль версий: если данные изменились, документ можно перевыпустить, сохранив историю прежних версий.

## Как открыть

Откройте проект и в боковом меню выберите раздел **Документы**. Откроется список всех документов проекта.

## Список документов

Главный экран модуля показывает все документы проекта в виде таблицы.

Вверху страницы расположены вкладки, которые помогают быстро отфильтровать список:

- **Все** — полный перечень документов.
- **Сгенерированные** — только документы, созданные системой по шаблонам.
- **Загруженные** — файлы, добавленные вручную (сканы, фотографии, готовые бумаги).

Под вкладками доступны фильтры:

- **Поиск по названию** — найти документ по имени.
- **Привязка** — показать документы, связанные с конкретной продажей, сделкой, контактом или компанией.
- **Тип файла** — DOCX, PDF, XLSX, JPG, PNG.
- **Дата создания** — диапазон дат.

Для каждого документа в таблице видны: название, тип файла, к чему он привязан, автор, дата и номер версии. Напротив каждой строки есть кнопка скачивания и меню дополнительных действий:

- **Просмотр** — открыть карточку документа.
- **Перегенерировать** — создать новую версию (доступно для сгенерированных документов).
- **Удалить** — убрать документ из проекта.

Чтобы добавить готовый файл, нажмите **Загрузить** в правом верхнем углу.

> 💡 Если список пуст, вы увидите подсказку «Нет документов» и кнопку для загрузки первого файла.

### Кто имеет доступ

- Просматривать и скачивать документы могут все участники проекта.
- Загружать файлы и запускать генерацию могут участники с правами на работу с данными.
- Удалять документы могут администраторы проекта.

## Карточка документа

Чтобы открыть карточку, нажмите на название документа в списке или выберите **Просмотр** в меню действий.

В карточке собрана вся информация об одном документе:

- **Шапка** — название, тип и размер файла, к каким записям он привязан (со ссылками на продажу, сделку, контакт или компанию), автор и дата создания.
- **Действия** — скачать, перегенерировать, удалить (набор кнопок зависит от ваших прав).
- **Версии** — для сгенерированных документов отображается список всех выпущенных версий с датой и автором. Любую прошлую версию можно скачать, текущая помечена отдельно.
- **Предпросмотр** — для PDF и изображений документ показывается прямо в карточке. Файлы DOCX нужно скачать для просмотра.
- **История** — журнал событий: кто создал документ, кто его перегенерировал, какие данные при этом менялись.

### Предупреждение об устаревших данных

Если документ был сгенерирован по шаблону, а после этого изменились исходные данные (например, реквизиты компании), в карточке появится баннер с предупреждением. Система подскажет, что значения в документе устарели, и предложит перевыпустить его. Вы можете сразу нажать **Перегенерировать** или оставить документ как есть.

> 💡 Перегенерация не стирает прежний документ — она создаёт новую версию, а все предыдущие остаются доступны в разделе «Версии».

## Шаблоны документов

Шаблоны — это заготовки в формате DOCX, в которые вставлены специальные переменные. При генерации система заменяет переменные на реальные данные из проекта и выдаёт готовый файл.

Чтобы открыть библиотеку шаблонов, перейдите в раздел **Документы** и нажмите ссылку **Шаблоны документов**, либо откройте подраздел шаблонов в меню документов.

Каждый шаблон показан карточкой, где видны его название, контекст привязки (продажа, сделка, контакт или компания), число переменных и сколько документов уже создано по этому шаблону. Из карточки можно перейти к редактированию или скачать сам файл шаблона.

> 💡 Если шаблонов ещё нет, система предложит создать первый — именно он включит автоматическую генерацию документов.

### Кто имеет доступ

Создавать и редактировать шаблоны могут руководители и администраторы проекта. Остальные участники пользуются уже готовыми шаблонами при генерации.

## Создание шаблона

Нажмите **Новый шаблон** в библиотеке шаблонов. Откроется форма из нескольких шагов.

1. **Название** — как шаблон будет называться в библиотеке.
2. **Контекст привязки** — к какой сущности относится шаблон: продажа, сделка, контакт или компания. От этого зависит, какие данные будут доступны для подстановки.
3. **Тип продажи** — если выбран контекст «Продажа», можно дополнительно ограничить шаблон одним типом продажи. Тогда шаблон будет предлагаться только при работе с продажами этого типа.
4. **Файл шаблона** — загрузите документ DOCX (можно перетащить файл в область загрузки). Допускается только формат DOCX.

Ниже формы есть справочник **Доступные переменные** — список всех значений, которые можно подставить в документ. Переменные сгруппированы по источникам данных:

- данные контакта (имя, телефон, email и другие);
- данные компании (название, ИНН, адрес и другие);
- данные сделки (название, сумма, источник);
- данные продажи (номер, дата оформления, значения её полей);
- данные проекта;
- даты (текущая дата, текущий год).

Рядом с каждой переменной есть кнопка копирования — нажмите её, чтобы скопировать переменную и вставить в свой DOCX-файл.

> 💡 Порядок работы простой: загрузите DOCX, откройте его в текстовом редакторе, вставьте нужные переменные вида `{{contact.name}}` в подходящие места и загрузите файл обратно. При генерации система сама подставит реальные значения.

Когда всё готово, нажмите **Создать**.

## Редактирование шаблона

Чтобы изменить шаблон, откройте его карточку в библиотеке и нажмите **Редактировать**. Форма редактирования повторяет форму создания, но поля уже заполнены текущими значениями.

Дополнительно на этом экране доступно:

- **Текущий файл шаблона** — его можно скачать или заменить новой версией DOCX.
- **Статистика** — сколько документов уже создано по этому шаблону.
- **Удаление шаблона** — кнопка убирает шаблон из библиотеки. Уже созданные по нему документы при этом не затрагиваются и остаются в проекте.

## Генерация документа по шаблону

Запустить генерацию можно из карточки сделки или продажи (вкладка «Документы»), а также из списка документов проекта. Откроется окно генерации:

1. **Выберите шаблон** — в списке доступны опубликованные шаблоны, подходящие к текущему контексту. Если подходящих шаблонов нет, система об этом сообщит.
2. **Выберите редакцию** — использовать текущую редакцию шаблона или ту, что действовала на момент исходной версии документа (актуально при перевыпуске).
3. Нажмите **Сгенерировать**.

Готовый документ появится в списке документов и будет привязан к нужной записи.

> 💡 Если в исходных данных не заполнены какие-то обязательные поля, документ всё равно создастся, но система предупредит, какие именно поля остались пустыми — их стоит дозаполнить и при необходимости перегенерировать документ.
